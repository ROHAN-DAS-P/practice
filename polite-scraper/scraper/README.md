# The Polite Scraper

## Target Classification

- **Target Site:** Books to Scrape (https://books.toscrape.com)
- **Purpose:** This site is a public practice sandbox built explicitly for developers to practice web scraping.
- **Scope:** The scraper is strictly limited to downloading the first 3 catalogue pages and visiting the resulting 60 book detail pages.
- **Data Collected:** Book title, product URL, clean price (GBP), availability, rating, description, source page, and fetch timestamp.
- **Robots.txt Check:** Requested `/robots.txt` — no robots file found (404 Not Found).

**I will not reuse this code on another site without checking its rules and terms first.**
